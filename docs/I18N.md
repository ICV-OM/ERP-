# Arabic / English Interface

- Arabic (`ar`) is the default locale.
- English (`en`) can be selected from the login page or application top bar.
- Arabic uses `dir="rtl"`; English uses `dir="ltr"`.
- The selected locale is stored in the non-sensitive `alturud_locale` cookie for one year.
- The locale cookie is validated server-side: only `en` is accepted explicitly; all other/missing values fall back to `ar`.
- Authentication, CSRF, RBAC, organization scoping and session cookies are unchanged by locale selection.

Main files:
- `src/lib/locale.ts` — locale type and cookie name.
- `src/lib/i18n.ts` — UI dictionaries and server locale reader.
- `src/lib/modules.ts` — localized module/screen definitions.
- `src/components/LanguageToggle.tsx` — language switch control.
- `src/app/globals.css` — RTL/LTR layout rules.
